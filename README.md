# To-Do List Manager

A menu-driven command-line to-do list built in Python for the Syntecxhub Internship Program.

## Features
- Add, view, mark as done, and delete tasks
- Tasks are saved to tasks.json, so they survive restarts
- File reading/writing with error handling
- Logic functions separated from input/output code
- Extra: optional tags and due dates

## How to run
1. Install Python 3
2. Download todo_manager.py
3. Open Command Prompt in the same folder and run:

   python todo_manager.py
